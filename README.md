\# 🚀 Predictive Maintenance Dashboard


\##  Overview

This project is an end-to-end predictive maintenance system that monitors sensor data, detects anomalies, predicts remaining useful life (RUL), and triggers alerts.


\## ⚙️ Features

\- Sensor trend visualization

\- Anomaly detection

\- Remaining Useful Life prediction

\- Alert system

\- Data drift detection

\- Automated pipeline simulation


##  Tech Stack

\- Python

\- Streamlit

\- Plotly

\- Docker

\- Kubernetes

\- Locust (Load Testing)
